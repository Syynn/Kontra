How the sources work

OEM portal: an official source to open in a new tab. Many manufacturers require their own login and subscription; this site does not bypass those restrictions.

NHTSA recalls: public U.S. model-level records when the remote API permits the browser connection. A secure server proxy is needed if cross-site requests are blocked. These are not VIN-specific. Confirm vehicle applicability using the manufacturer's VIN-based system before scheduling work.

Technician-added cards: steps and tool lists saved in this iPhone browser with a source URL and document reference. Their contents are not independently verified by this software. Confirm against the current OEM publication.

Diagnostics: generic educational fault-isolation guides. They are not a scan tool, do not connect to a vehicle, and cannot replace OEM electrical tests, technical bulletins or safety instructions.
